# Maxpriblog

A personal blog featuring articles on various topics.

## Structure
- `index.html`: The main landing page.
- `style.css`: Stylesheets for the blog.
- `articles/`: Contains individual blog posts.

## Getting Started
To view the blog, simply open `index.html` in your web browser.

## Adding a New Article
1. Create a new HTML file inside the `articles/` folder.
2. Use the existing article files as a template for structure and formatting.
3. Add the article title, author, date, and content in standard HTML.
4. Save the file with a descriptive name, such as `new-article-title.html`.

## Contributing
- Fork or copy this project to make changes.
- Add new article files under `articles/` and update any navigation links if necessary.
- Keep article filenames simple, lowercase, and hyphen-separated.
- Test your changes by opening `index.html` and verifying the new article appears and renders correctly.
- Submit a pull request or share the updated files for review.
